# RX-105 Xi Gundam Pet

Version 1 of **Ξ-105**, a custom animated ChatGPT Work pet inspired by the RX-105 Xi Gundam.

![Ξ-105 animation preview](Pets/Ξ-105/previews/final/all-states.gif)

## Included

- Validated v2 sprite sheet with nine animation states and sixteen look directions
- Individual state previews, complete motion preview, and look-direction loop
- Approved front and rear character references
- Generation prompts and validation reports

## Final assets

- Sprite sheet: `Pets/Ξ-105/final/spritesheet-extended.png`
- Full preview: `Pets/Ξ-105/previews/final/all-states.gif`
- Look loop: `Pets/Ξ-105/previews/final/look-loop.gif`
- Approved rear: `Pets/Ξ-105/references/canonical-back-v3.png`

The final sheet is a transparent PNG using the ChatGPT Pets v2 layout: 1536×2288 pixels, eight columns, eleven rows, and 192×208-pixel cells.
